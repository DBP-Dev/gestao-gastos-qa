# Área do QA

Tudo o que o QA produz fica aqui, separado por sprint.

```
qa/
├── modelos/            modelos de plano, caso de teste, bug e relatório
└── sprint-01/
    ├── plano-de-teste.md
    ├── casos-de-teste/  um arquivo por história (US-101-busca-de-contas.md…)
    ├── bugs/            um arquivo por bug (BUG-001.md…), também abertos como Issues
    ├── evidencias/      prints, vídeos e arquivos gerados
    ├── regressao.md     checklist da versão anterior
    └── relatorio-de-teste.md
```
